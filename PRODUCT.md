# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Howard, transferring visualizer tools to another PC and GitHub/Cloudflare accounts.
## Product Purpose
Independent yard-photo visualization using the original turf workflow and catalog.
## Stack
Static HTML/CSS and browser JavaScript with an optional Cloudflare Pages function for image-provider requests.
## Capabilities and Constraints
Local photo upload, product choices, putting-green options and project planning. AI rendering is paused until the user configures their own Cloudflare function and provider key. Generated images are concept previews. No new paid renders are required for the portable export.
## Evidence on Hand
Recovered original visualizer assets, catalog, rules, prompt and color-matching modules; local shell preserves their behavior and bundled fonts.
